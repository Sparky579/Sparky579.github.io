Publications

CHI '26

BAIT: Visual-illusion-inspired Privacy Preservation for Mobile Data Visualization

Sizhe Cheng, Songheng Zhang, Dong Ma, Yong Wang

Stacks an optimized decoy chart over a real one, so the owner reads the truth up close while a shoulder surfer at a distance is misled — driven by an explicit model of human perception across viewing distances. Validated in a 32-participant lab study and a 12-participant field study.

DOIarXiv

UIST '25

RAGTrace: Understanding and Refining Retrieval-Generation Dynamics in Retrieval-Augmented Generation

Sizhe Cheng, Jiaping Li, Huanchen Wang, Yuxin Ma

An interactive evaluation system that opens the RAG black box: multi-level analysis from aggregate performance down to per-chunk retrieval relevance, generation fidelity, and cross-component interaction — users trace knowledge provenance, localize failure cases, and iterate on retrieval strategy in place.

DOIarXiv

UIST '26

EvoMaestro: Toward Interpretable and Steerable LLM-Driven Program Evolution

Feng Liang, Sizhe Cheng, Yikai Li, Ruijie He, Xiaolin Wen, Yong Wang

Turns black-box LLM program evolution into something an expert can read and steer: an evolution overview of winning and failed strategies, a radial tree of the full evolution history, and natural-language code explanation — plus merging complementary solutions and steering by prompt.

DIS '26

Proteus: Shapeshifting Desktop Visualizations for Mobile via Multi-level Intelligent Adaptation

Can Liu, Sizhe Cheng, Feng Liang, Zhibang Jiang, Lingru Huang, Kavinda Athapaththu, Yong Wang

An LLM-driven multi-agent system that parses live desktop charts and re-authors them for mobile across a three-level design space: global topology, reference frame, and visual elements.

Jiongchi Yu, Xiaolin Wen, Sizhe Cheng, Xiaofei Xie, Qiang Hu, Yong Wang

Surveys human-in-the-loop fuzzing and lays out a research agenda across human monitoring, human steering, and human–LLM collaboration.
